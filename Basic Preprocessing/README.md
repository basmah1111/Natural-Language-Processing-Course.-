# 🛠 Basic Text Preprocessing

This folder contains the fundamental techniques used to clean and prepare text data for NLP models.

## 📋 Contents
In this section, I have implemented:
* **Tokenization:** Splitting text into words or sentences.
* **Stop Words Removal:** Filtering out common words that don't add much meaning.
* **Stemming & Lemmatization:** Reducing words to their root forms.
* **Text Cleaning:** Removing special characters, numbers, and extra spaces.

## 🚀 How to use
The scripts/files here demonstrate how to handle raw text before feeding it into more advanced algorithms like RNNs or Transformers.
