# ✨ التقنيات الحديثة في معالجة اللغات - Modern Techniques

يضم هذا القسم أحدث المنهجيات والتقنيات المعاصرة في عالم الـ NLP، والتي تُستخدم لبناء تطبيقات ذكية تحاكي القدرات البشرية في فهم وتوليد النصوص.

## 📋 ماذا يوجد في هذا المجلد؟
ركزت في هذا القسم على استكشاف وتطبيق:
* **النماذج اللغوية الكبيرة (LLMs):** مثل التعامل مع عائلة نماذج GPT و Llama.
* **توليد النصوص (Text Generation):** تقنيات بناء شات بوت (Chatbots) وأنظمة توليد المحتوى.
* **ضبط النماذج (Fine-tuning):** كيفية تطويع النماذج الضخمة لخدمة مهام محددة بدقة عالية.
* **التعامل مع الـ Prompt Engineering:** فن صياغة الأوامر للحصول على أفضل النتائج من الذكاء الاصطناعي.

## 🌟 مهارات إضافية
* التعامل مع المكتبات الحديثة مثل **LangChain** أو **OpenAI API**.
* فهم هندسة النماذج التوليدية (Generative AI).
