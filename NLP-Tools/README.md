أدوات NLP (Natural Language Processing Tools)

هذا المجلد يحتوي على جميع الأدوات والملفات المتعلقة بمعالجة اللغات الطبيعية (NLP) التي تم استخدامها أو جمعها خلال الكورس.

محتوى المجلد
ملفات وأكواد تساعد في التعامل مع النصوص العربية والإنجليزية.

أدوات لتنظيف النصوص، التوكنيزشن (Tokenization)،
إزالة التكرارات، وتصحيح الأخطاء اللغوية.

مكتبات جاهزة أو سكريبتات صغيرة لتسهيل العمل على مشاريع NLP.

كيفية الاستخدام

افتحي الملفات الموجودة داخل المجلد حسب الحاجة.
يمكن فتح الأكواد مباشرة أو تعديلها لتناسب مشروعك.
تأكدي من تثبيت أي مكتبات مطلوبة إذا كنتِ تعملين على بايثون (مثل nltk, spacy, arabert).
