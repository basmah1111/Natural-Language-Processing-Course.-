# 🧠 Recurrent Neural Networks (RNN) for NLP

This section focuses on using Deep Learning models to handle sequential data and understand the context of sentences.

## 📋 What's Included?
In this folder, you will find implementations and tasks related to:
* **Simple RNNs:** Understanding how neural networks remember previous inputs.
* **LSTM (Long Short-Term Memory):** Tackling the vanishing gradient problem for better long-term dependency.
* **GRU (Gated Recurrent Units):** A more efficient version of LSTMs.
* **Text Generation/Classification:** Examples of using these models on real datasets.

## 🛠 Tools Used
* **TensorFlow / Keras**
* **NumPy**
* **Word Embeddings (Word2Vec / GloVe)**
