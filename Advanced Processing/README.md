# 🚀 معالجة اللغات الطبيعية المتقدمة - Advanced NLP

يحتوي هذا المجلد على مواضيع وتقنيات متقدمة في مجال معالجة اللغات الطبيعية، حيث يتم التركيز على النماذج التي تفهم السياق بعمق أكبر.

## 📋 محتويات القسم
في هذا الجزء، قمت بالعمل على:
* **آلية الانتباه (Attention Mechanism):** فهم كيف يركز النموذج على كلمات معينة في الجملة.
* **المحولات (Transformers):** التعامل مع نماذج مثل BERT و GPT وفهم بنيتها الأساسية.
* **نقل التعلم (Transfer Learning):** استخدام نماذج مدربة مسبقاً وتعديلها لمهام محددة.
* **التعامل مع المهام المعقدة:** مثل استخراج الكيانات (NER) أو تحليل العلاقات بين الجمل.

## 🛠 الأدوات المستخدمة
* **Hugging Face Transformers**
* **PyTorch / TensorFlow**
* **Large Language Models (LLMs)**
